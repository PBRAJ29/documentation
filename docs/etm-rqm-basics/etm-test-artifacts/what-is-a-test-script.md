# What is a Test Script?

## Test Implementation



A document specifying a sequence of actions for the execution of a test. Also known as Test Procedure.



A Test Script (TS) specifies the concrete test steps necessary to test one or more requirements by describing in each test step what shall be done and which reaction is expected. If needed a test script uses the defined execution variables or test data. Together with the test case definition and the test execution record a unique version of a test specification is defined.

## Test Script Sections

Test Script contains the overall information like state, originator, owner, type (manual, command line...), test data, and its description
