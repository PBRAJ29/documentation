# What is a Test Plan?

## Test Planning



A document defining the scope, approach, resources, and schedule of intended test activities… It is a record of the test planning process.



## Test Plan

A Test Plan (TP) describes which tests are conducted on which application; contains the test cases, test scripts and test suites in scope of one application. In addition, defines when the tests will be executed by defining test iterations as part of a test schedule as well as the execution environments needed to execute the tests.



## Test Plan Sections

Test Plan contains the overall information like state, originator, owner, priority, and its description
