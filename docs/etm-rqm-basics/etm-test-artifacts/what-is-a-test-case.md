# What is a Test Case?

## Test Analysis & Design



A set of input values, execution preconditions, expected results and execution post-conditions, developed for a particular objective or test condition, such as to exercise a particular program path or to verify compliance with a specific requirement.

## Test Case

A Test Case (TC) specifies the abstract test conditions and measures to verify one or more requirements.

## Test Case Sections

Test Case contains the overall information like state, originator, owner, priority, and its description
